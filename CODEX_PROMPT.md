# Задание для Codex: сайт «Живые ёлки к 31 декабря»

Работаешь в папке `C:\Users\panki\Desktop\elki-wow-demo`. Полное ТЗ — `TZ.md`, прочитай его целиком перед началом. Ниже порядок работы и то, что важно не перепутать.

## Главное

- 4 экрана для записи рилса на ноутбуке (1440×900). Не полноценный сайт.
- Атмосфера: **минималистично, но празднично** — свет гирлянд, боке, точечный красный, без клипарта.
- **Композиция по `refs/composition.webp`, а не стиль.** Берёшь раскладку: огромное слово сверху во всю ширину, главный предмет строго по центру, короткие подписи слева и справа с тонкими линиями-выносками к предмету, кнопка-пилюля внизу по центру, маленькие карточки в нижних углах, шапка «лого — ссылки — кнопка». Не копируй плюшевую ёлку, Санту, конверт, шрифт и цвета референса.
- Ёлка не перекрывает слово сверху, текст никогда не лежит на ёлке.
- `Desktop/dodo-wow-demo` можно смотреть только как технический пример (`tools/build-seq.sh`, `tools/record.py`). Его вау-эффекты, сетку и маски не повторять.

## Шаг 1. Картинки

Сгенерируй своим инструментом генерации изображений все картинки из раздела «Картинки» в `TZ.md`: 4 опорных кадра в `frames/` и 4 вырезанных объекта в `assets/img/`. Сначала `frames/1-tree.png`, остальные — по нему как по референсу, чтобы ёлка везде была одна. Стоки не бери. Если что-то не получилось, напиши об этом в отчёте, а не ставь молча заглушку.

Ролики Kling генерирует Иван позже и кладёт в `video/`. Сейчас их нет: сайт должен работать на кадрах-постерах, а `tools/build-seq.sh` — нарезать ролики в `assets/seq/1…3/` и `manifest.json`, когда они появятся, без правки кода.

## Шаг 2. Сайт

- Статика: `index.html`, `styles.css`, `script.js`, `assets/`, без сборщиков. Все пути относительные (сайт будет жить в подпапке GitHub Pages).
- GSAP + ScrollTrigger + Lenis с CDN, версии фиксированные.
- Экраны 2 и 4 запинены, скролл крутит кадры на canvas с учётом devicePixelRatio. Экран 1 проигрывается сам при загрузке.
- Анимировать только transform, opacity, clip-path и canvas. 60 fps.
- Режим `?demo=1` — по таблице из `TZ.md`, тайминги константами в начале `script.js`. Скрипт записи `tools/record.py`.
- `noindex, nofollow` в `<head>`, в футере «Хвоя · Демо-сайт. Цены и сроки условные».
- Мобильная версия не нужна, но на ширине меньше 900 px ничего не ломается.
- Тексты только на русском и только из `TZ.md`.
- Проверь в браузере 1440×900, сохрани 4 скриншота экранов и 1 после клика по кнопке в `shots/`.

## Шаг 3. Публикация на GitHub

1. Git уже инициализирован. Добавь `.gitignore` (`node_modules/`, `*.log`, `.DS_Store`). Коммить по шагам.
2. Создай публичный репозиторий `elki-wow-demo` в аккаунте, под которым залогинен `gh`: `gh repo create elki-wow-demo --public --source . --push`.
3. Включи GitHub Pages из ветки `main`, папка `/`: `gh api -X POST repos/{owner}/elki-wow-demo/pages -f "source[branch]=main" -f "source[path]=/"`.
4. Дождись сборки (`gh api repos/{owner}/elki-wow-demo/pages/builds/latest`) и открой ссылку — проверь, что картинки и скрипты грузятся.
5. Ролики в `video/` в репозиторий не клади (добавь `video/` в `.gitignore`), нарезанные кадры `assets/seq/` — клади.
